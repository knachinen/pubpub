## 첫번째 프로젝트

첫 프로젝트는 무작위 단어를 제시하여,  
해당 주제로 글을 쓰는 앱이다.  

## 작업 명세서

> [!INFO] 프로젝트 정보
> 
> **코드:** `p01_w01-1`
> 
> **설명:** 프로젝트 01. 01주차. 1일 (월요일)

> [!ABSTRACT] 핵심 아이디어: 무작위 단어 글쓰기 도우미
> 
> 이 앱은 사용자가 입력한 웹주소의 텍스트 콘텐츠를 기반으로 글쓰기를 돕는 도구입니다.
> 
> 1. 웹주소에서 텍스트 콘텐츠를 추출합니다.
>     
> 2. 추출된 텍스트에서 **무작위 단어** 하나를 제시합니다.
>     
> 3. 사용자는 이 단어를 사용하여 글을 작성하고 저장합니다.
>     

> [!CODE] 기술 스택
> 
> - **프레임워크:** React Native
>     
> - **개발 도구:** Expo
>     

> [!TASK] 주요 기능 목록
> 
> - ✅ 웹주소(URL) 입력 필드
>     
> - ✅ 텍스트 추출 및 무작위 단어 제시 기능
>     
> - ✅ 글쓰기 전용 입력창 (에디터)
>     
> - ✅ 마크다운(`.md`) 형식으로 파일 저장 기능
>     
> - ✅ 이전에 저장한 파일 탐색 및 불러오기
>     

> [!TIP] 디자인 가이드라인
> 
> - **미니멀 디자인 (Minimalistic Design):** 사용자가 오직 글쓰기 자체에만 집중할 수 있도록 불필요한 요소는 최소화합니다.
>     
> - **핵심:** 깔끔하고 방해 없는(distraction-free) 사용자 경험 제공.
>
