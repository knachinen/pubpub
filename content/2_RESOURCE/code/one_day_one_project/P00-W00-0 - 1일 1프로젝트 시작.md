## 1일 1프로젝트 

1일 1프로젝트를 리추얼로 시작했다.  

간단한 아이디어를 바이브코딩으로 구현하고,  
그 과정을 기록하기로 한다.  

바이브코딩은 Gemini CLI 와 AntiGravity 를 이용한다.  

## 작업 규칙

먼저 프로젝트 환경을 설정했다.  

Gemini 로 1일 1프로젝트 계획을 정리한 뒤,  
다음과 같이 몇가지 작업 규칙을 정했다.  

> [!NOTE] 작업 규칙
> 
> - 한글로 답변
> - 깃 환경 설정
> - 계획과 체크리스트를 제시하고, 승인을 받을 것.
> - 승인 받은 계획과 체크리스트를 각각 문서로 저장.
> - 체크리스트 작업 하나가 끝나면, 깃 커밋을 진행.
> - 계획에 따른 체크리스트의 모든 작업이 끝날 경우 확인 요청할 것.
> - 각 프로젝트는 '[프로젝트넘버]\_[주차넘버]-[요일넘버]' 디렉토리 안에 작성. (예: 첫번째 프로젝트, 1주차, 월요일. p01-w01-1)
> - 문서는 생성된 순서대로 넘버링. (예: 01_plan.md, 02_checklist.md)
