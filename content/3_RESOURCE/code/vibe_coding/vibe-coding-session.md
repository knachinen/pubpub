> 
> ### 6. 제품 요구사항 명세서 작성 (PRD)
> 
> ### 7. 단계별 구현 계획서 작성
> 
> - 예: _단계별 구현 계획 작성_
> 	- _각 단계는 독립적으로 실행 가능하여 검증할 수 있어야 함._

> 
> - 위 단계별 구현 계획서에서 단계별로 각각 따로 작성
> - 예: _[1단계] 프로젝트 기반 설정 및 메인 탭바 (UI Skeleton) 상세 구현 명세서 작성_
