## 첫번째 프로젝트

첫 프로젝트는 무작위 단어를 제시하여,  
해당 주제로 글을 쓰는 앱이다.  

## 작업 명세서

```
## 프로젝트
  
- 프로젝트 코드: p01_w01-1
- 설명: 프로젝트 01. 01주. 1일 (월요일)
  
## 아이디어
  
- 무작위 단어로 글쓰기
- 입력받은 웹주소에서 텍스트 컨텐츠를 가져옴
- 텍스트 컨텐츠에서 무작위로 단어를 제시
- 해당 단어로 글을 쓰고 저장
  
## 기술
  
- React Native
- Expo
  
# 기능
  
- 웹주소 입력
- 무작위 단어 제시
- 글쓰는 입력창
- 마크다운 저장 (.md)
- 이전에 저장한 파일 탐색 및 불러오기
  
## 디자인
  
- 미니멀 디자인 (Minimalistic Design)
```

## 결과

그 다음부터는 작업계획과 작업 체크리스트 문서를 작성하며,  
코드구현 작업을 시작하였다.  

결과는..  
실패.  

## 디버깅 

파일을 읽고 쓰는 간단한 모듈 구현이 되지 않는다.  
원래 계획은 1시간 코드 구현이었는데,  
디버깅을 하느라 2~3시간이 소요되었다.  
그러고도 디버깅이 되지 않았다.  

에이전트가 아닌 수동 디버깅을 위해,  
코드분할을 마지막으로 요청했는데,  
그마저도 오류가 났다.  

일단 오늘은 여기까지.  
내일 이어서 작업해야할지,  
아니면 프로젝트 계획에 따라,  
그냥 새로운 프로젝트를 할지 생각을 해봐야겠다.
