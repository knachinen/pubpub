## 과정

구현과정에서 지시한대로 잘 따르지 않았다.  

### 체크리스트 

어제 작업규칙 문서를 읽게 하였는데도,  
하나의 작업 후에 체크리스트를 업데이트를 하지 않는다.  

Gemini CLI 내부 체크리스트 때문에 혼동이 있는 것 같다.  

처음에 문서를 명시해서 업데이트를 하라고 해야지만 그제서야 문서에 관심을 가진다.  
그것도 다음 작업부터는 다시 무시한다.  
파일이름을 명시하는 것으로도 안되고, @로 지정해줘야 한다.  

작업 하나하고 멈추고, 체크리스트 문서를 업데이트하고 승인을 받으라고 해줘도,  
말만 승인받겠다고 하고 다음 작업으로 넘어간다.  

### 그밖에 

`cd` 명령으로 디렉토리를 변경하려고 하는데,  
`&&` 으로 디렉토리 변경과 작업 명령을 동시에 하라고 하라고 해줘야 한다.  

Expo CLI 를 쓰려고 하는데,  
`npx expo` 를 사용하라고 해줘야 한다.  

기본으로 만들어진 파일이 ts 인데,  
js 파일을 만들려고 시도한다.  
타입스크립트로 작성을 하라고 해줘야 한다.
