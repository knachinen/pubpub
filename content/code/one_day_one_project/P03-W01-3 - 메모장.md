## 작업 요청

이번에는 AntiGravity 로 진행했다.  

`mvp 로서 아주 간단한 메모장`

몇 마디로 아주 간단하게 요청을 했는데,  
결과적으로 Gemini CLI 와는 다르게 알아서 잘 구현해줬다.  


## 구현 계획 

작업 요청에 따라 아래와 같은 계획을 작성해주었다.  

> [!NOTE] 프로젝트 목표 설명
> 
> **기술 스택:** React Native 및 TypeScript
> 
> **목표:** $\text{MVP}$ (Minimum Viable Product) 메모장 앱 개발
> 
> **핵심 기능:**
> 
> 1. $\text{CRUD}$ **작업:** 메모 생성, 조회, 수정, 삭제
>     
> 2. **데이터 저장:** 로컬 저장소 ($\text{AsyncStorage}$)
>     
> 3. $\text{UI/UX}$**:** 다크/라이트 모드 지원
>     
> 4. **디자인 컨셉:** 프리미엄 글래스모피즘 (Glassmorphism)
>     

> [!CODE] 구현된 변경 사항: 프로젝트 구조 및 파일별 역할
> 
> **디렉토리:** `p03_w01-3_notepad`
> 
> ### App.tsx (메인 진입점)
> 
> - `notes` 상태 및 `themeMode` 상태 관리.
>     
> - `SafeAreaProvider`를 사용하여 안전 영역 $\text{Layout}$ 처리.
>     
> - 테마 토글 ($\text{☀️/🌙}$) 기능 구현.
>     
> 
> ### src/components/NoteList.tsx
> 
> - 메모 목록 표시 및 $\text{UI}$ 구현.
>     
> - `useSafeAreaInsets`를 활용한 패딩 처리.
>     
> - 메모 삭제 전 `Alert.alert`를 통한 확인 절차 구현.
>     
> - 동적 스타일링을 위한 `theme` $\text{prop}$ 수신 및 적용.
>     
> 
> ### src/components/NoteEditor.tsx
> 
> - 메모 작성 및 수정 $\text{Interface}$.
>     
> - 제목 입력 필드에 자동 포커스 기능 구현.
>     
> - 동적 스타일링을 위한 `theme` $\text{prop}$ 수신 및 적용.
>     
> 
> ### src/utils/storage.ts
> 
> - `saveNotes` / `loadNotes`: $\text{AsyncStorage}$를 이용한 메모 데이터 영구 저장 및 불러오기.
>     
> - `saveTheme` / `loadTheme`: 현재 테마 설정 저장 및 불러오기.
>     
> 
> ### src/styles/theme.ts
> 
> - `ThemeColors` $\text{Interface}$ 정의.
>     
> - `THEMES` 객체 내 다크/라이트 테마 색상 정의 및 내보내기.
>     
> - `createCommonStyles`를 통한 공통 $\text{Style}$ 동적 생성 및 내보내기.
>     

> [!CHECKBOX] 검증 목록 (Validation Checklist)
> 
> - [ ] $\text{Expo}$에서 앱 실행 ($\text{Android/iOS}$) 확인.
>     
> - [ ] $\text{CRUD}$ (생성, 조회, 수정, 삭제) 작업 동작 확인.
>     
> - [ ] 앱 재시작 후 메모 데이터가 유지되는지 확인.
>     
> - [ ] 노치 디바이스에서 안전 영역 레이아웃이 올바른지 확인.
>     
> - [ ] 메모 삭제 확인 기능(`Alert.alert`) 동작 확인.
>     
> - [ ] 다크/라이트 모드 토글 및 설정 유지 확인.
>
